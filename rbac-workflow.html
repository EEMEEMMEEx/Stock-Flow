Supabase Row-Level Security (RLS) SQL Script

คำสั่ง SQL สำหรับรันใน Supabase SQL Editor เพื่อกำหนดสิทธิ์ความปลอดภัยในระดับแถวข้อมูล (Row Level Security)

Policy 1: Allow Users to Confirm Own Order Receipt withdrawal_orders 
-- อนุญาตให้ User ทั่วไปเปลี่ยนสถานะบิลของตนเองเป็น 'completed'
CREATE POLICY "Users can complete their own orders" 
ON public.withdrawal_orders 
FOR UPDATE 
USING (auth.uid() = requested_by)
WITH CHECK (status = 'completed');

ให้เฉพาะผู้เบิกของบิลนั้นๆ กดปุ่มยืนยันการรับของเพื่อเปลี่ยนเป็นสถานะ completed ได้เท่านั้น

Policy 2: Admin Full Order Control Policy withdrawal_orders 
-- อนุญาตให้ Admin มีสิทธิ์อนุมัติ/ปฏิเสธ หรือแก้ไขได้ทุกบิล
CREATE POLICY "Admins have full access to all orders" 
ON public.withdrawal_orders 
FOR ALL 
USING (
  EXISTS (
    SELECT 1 FROM public.profiles 
    WHERE id = auth.uid() AND role = 'admin'
  )
);

แอดมินสามารถอนุมัติ ปฏิเสธ หรือแก้ไขบิลเบิกได้ทุกรายการในระบบ

Policy 3: Authenticated Users Create Orders withdrawal_orders 
-- อนุญาตให้ผู้ใช้ที่เข้าสู่ระบบสามารถสร้างใบเบิกใหม่ได้
CREATE POLICY "Users can create withdrawal orders" 
ON public.withdrawal_orders 
FOR INSERT 
WITH CHECK (auth.uid() = requested_by);

ผู้ใช้ทุกคนในระบบสามารถส่งใบเบิกของตนเองเข้าสู่สถานะ pending ได้

Policy 4: Public Read Access for Inventory Items items, projects 
-- อนุญาตให้ผู้ใช้ทุกคนอ่านรายการสินค้าและโครงการเพื่อการเบิกจ่าย
CREATE POLICY "All users can view items and projects" 
ON public.items 
FOR SELECT 
USING (true);

ให้สิทธิ์ค้นหาและดูรายการสินค้าแก่ผู้ใช้ทุกคนเพื่อนำสินค้าใส่ตะกร้า
