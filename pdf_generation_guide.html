1 ภาพรวมสถาปัตยกรรมระบบ PDF (Architecture Overview)

Client-Side Architecture

โปรเจกต์ Stock-Flow-app ออกแบบระบบสร้างเอกสาร PDF โดยเน้นการประมวลผลฝั่ง Client-Side (React Component Engine) เพื่อความรวดเร็ว ประสิทธิภาพสูง ไม่ต้องพึ่งพาเซิร์ฟเวอร์ภายนอก สามารถสร้างและดาวน์โหลดเอกสาร PDF ได้ทันทีบนเบราว์เซอร์ของผู้ใช้

2 Client-Side PDF Generation (@react-pdf/renderer)

Primary Engine

ในการใช้งานจริงหน้า Withdrawals.jsx (หน้าใบเบิกจ่ายอุปกรณ์) และ Reports.jsx ระบบจะเรียกใช้แบบแม่พิมพ์ PDF Component จากไฟล์ src/lib/pdf-templates.jsx มาประมวลผลเป็นไฟล์ PDF ไบนารีผ่าน Browser แบบ ไดนามิก (Dynamic Import)

ส่วนประกอบหลักของ React-PDF Templates

DeliveryNotePDF

ใบนำส่งอุปกรณ์
  • • Header & Address: หัวกระดาษบริษัท ฟอร์ท คอร์ปอเรชั่น จำกัด (มหาชน) พร้อมโลโก้
  • • Dynamic Items Grid: ตารางแสดงลำดับ, รายการ, จำนวน (พร้อมหน่วย เช่น "1 ชุด"), Serial Number / Part Number
  • • Row Padding: เติมตารางว่างให้ครบอย่างน้อย 15 แถวเสมอ (MIN_ROWS = 15) เพื่อความสวยงาม
  • • Remark Section: แสดงจุดประสงค์การเบิกจ่ายใต้ตาราง
  • • Signatures Block: ลายเซ็นผู้ส่งของและผู้รับของแบบยืดหยุ่น (wrap={false} ป้องกันถูกตัดครึ่งหน้า)

StockReportPDF

รายงานสรุปสต็อก
  • • Report Header: หัวข้อรายงานสรุป พร้อมวันที่ออกรายงานแบบไทย
  • • Stock Balance Table: ตารางเปรียบเทียบข้อมูลโครงการ, วัสดุ, ยอดรับเข้า (+สีเขียว), ยอดเบิกจ่าย (-สีส้ม), ยอดคงเหลือ
  • • Auto Layout: คำนวณสัดส่วนความกว้างคอลัมน์อัตโนมัติ
ตัวอย่างการสร้าง Blob และสั่งดาวน์โหลดใน React Page src/pages/Withdrawals.jsx 
// Dynamic Import เพื่อลด Bundle Size ในตอนเริ่มต้น
const { DeliveryNotePDF } = await import('@/lib/pdf-templates.jsx');
const { pdf } = await import('@react-pdf/renderer');

// สร้าง React PDF Document Object
const doc = <DeliveryNotePDF order={selectedOrder} items={orderItems} profile={profile} />;

// แปลง Document เป็น Blob URL
const blob = await pdf(doc).toBlob();
const url = URL.createObjectURL(blob);

// สั่งเปิดหรือดาวน์โหลดไฟล์ PDF
const a = document.createElement('a');
a.href = url;
a.download = `DeliveryNote_${selectedOrder.id.split('-')[0]}.pdf`;
a.click();
URL.revokeObjectURL(url);

3 การออกแบบและกำหนดรูปแบบหน้าตา PDF (PDF Layout & UI/UX Design Systems)

Design Specs

การกำหนดเลย์เอาต์หน้าตาเอกสาร PDF ผ่าน @react-pdf/renderer ใช้ไวยากรณ์สไตล์คล้าย React Native โดยคำนวณสัดส่วนองค์ประกอบให้สอดคล้องกับขนาดกระดาษมาตรฐาน A4 ดังรายละเอียดโครงสร้างต่อไปนี้:

1. Page Canvas & Margins

ตั้งค่าขนาด A4 (size="A4") ระยะขอบกระดาษ padding: '10mm 15mm 30mm 15mm' สีพื้นหลังขาวบริสุทธิ์ #ffffff เพื่อให้เข้ากับเครื่องพิมพ์ทุกรุ่น

2. Header & Branding

จัดเลย์เอาต์แนวนอน (flexDirection: 'row') แสดงโลโก้บริษัทคู่กับชื่อบริษัทไทย-อังกฤษ โดยชื่อไทยใช้โทนสีฟ้า #5b9bd5 ขนาด 28pt Bold

3. Table Grid Architecture

แบ่งสัดส่วนคอลัมน์ตารางเป็นเปอร์เซ็นต์ด้วย Flexbox พร้อมเส้นขอบคมชัดขนาด 1px (borderWidth: 1) และขอบล่างแถวละ 1px

ตารางอ้างอิงคุณสมบัติสไตล์ที่ใช้กำหนดรูปแบบ PDF

องค์ประกอบ (UI Component) React-PDF Style Property รายละเอียดและวัตถุประสงค์
หน้ากระดาษหลัก (Page) padding: '10mm 15mm 30mm 15mm' กำหนดระยะขอบกระดาษ เว้นขอบล่าง 30mm เพื่อรองรับส่วนลายเซ็น
ตาราง (Table Grid) flexDirection: 'row', width: '100%' สร้างแถวตารางแบบ Flexbox และขยายเต็มความกว้างกระดาษ
ความกว้างคอลัมน์ (Columns) width: '8%', '52%', '10%', '30%' แบ่งสัดส่วนคอลัมน์ ลำดับ, รายการ, จำนวน, S/N ให้สมดุลพอดีหน้า A4
แถวตารางขั้นต่ำ (Padded Rows) minHeight: 16, paddedItems.length = 15 ตรึงความสูงแถว 16px และเติมตารางว่างให้ได้ 15 แถวเสมอ
กล่องลายเซ็น (Footer Signatures) wrap={false}, width: '40%' ป้องกันส่วนลายเซ็นถูกตัดครึ่งหน้า และแบ่ง 2 ฝั่งซ้าย-ขวาอย่างสวยงาม

4 HTML/CSS Print Template Standard (delivery-note.html)

Standard Master

ไฟล์ delivery-note.html คือแม่แบบเอกสาร HTML ที่ได้รับการออกแบบโครงสร้างตามมาตรฐานแบบฟอร์มเอกสารทางราชการ/บริษัท (FORTH DOPA standard) สำหรับพิมพ์ผ่านเบราว์เซอร์ (window.print())

จุดเด่นของการจัดเลย์เอาต์แบบ CSS Print

@page CSS Directive กำหนดขนาดกระดาษ size: A4 portrait พร้อมตั้งค่าระยะ Margin 10mm 15mm อย่างแม่นยำ
Page Break Prevention ใช้ break-inside: avoid เพื่อป้องกันไม่ให้ส่วนตารางสรุปและกล่องลายเซ็นถูกตัดขาดกลางหน้า
Exact Unit Sizing ใช้หน่วย มิลลิเมตร (mm) และ พอยต์ (pt) ในการระบุขนาดฟอนต์และขอบตารางเพื่อให้ได้ผลลัพธ์การพิมพ์ตรงกับแบบฟอร์มจริง

5 การตั้งค่าฟอนต์ภาษาไทย (Thai Font Configuration)

Critical Setup

ปัญหาสำคัญในการสร้างเอกสาร PDF คือการแสดงผลภาษาไทยไม่ถูกต้องหรือเป็นสี่เหลี่ยมโตฟู (Glyph Missing) ในโปรเจกต์นี้แก้ปัญหาโดยการลงทะเบียนไฟล์ฟอนต์ภาษาไทยมาตรฐาน (THSarabunNew) เข้ากับระบบ React-PDF

การลงทะเบียนฟอนต์สำหรับ React-PDF (THSarabunNew)

ทำการลงทะเบียนไฟล์ฟอนต์ TTF แบบครบทุกน้ำหนัก (Regular, Bold, Italic, BoldItalic) จากไดเรกทอรี public/fonts/ 

Font.register({
  family: 'THSarabunNew',
  fonts: [
    { src: '/fonts/THSarabunNew.ttf' },
    { src: '/fonts/THSarabunNew Italic.ttf', fontStyle: 'italic' },
    { src: '/fonts/THSarabunNew Bold.ttf', fontWeight: 'bold' },
    { src: '/fonts/THSarabunNew BoldItalic.ttf', fontWeight: 'bold', fontStyle: 'italic' }
  ]
});

6 ตัวอย่างการสร้าง PDF Component สไตล์ Stock-Flow

Full Example

ตัวอย่างโครงสร้างไฟล์ pdf-templates.jsx สรุปสำหรับการสร้างแบบนำส่งอุปกรณ์มาตรฐาน: 

import React from 'react';
import { Document, Page, Text, View, StyleSheet, Font, Image } from '@react-pdf/renderer';

// 1. ลงทะเบียนฟอนต์ภาษาไทย
Font.register({
  family: 'THSarabunNew',
  fonts: [
    { src: '/fonts/THSarabunNew.ttf' },
    { src: '/fonts/THSarabunNew Bold.ttf', fontWeight: 'bold' }
  ]
});

// 2. กำหนด StyleSheet สไตล์เอกสารทางการ
const styles = StyleSheet.create({
  page: {
    fontFamily: 'THSarabunNew',
    padding: '10mm 15mm 30mm 15mm',
    fontSize: 12,
    color: '#000',
    backgroundColor: '#fff'
  },
  headerSection: { flexDirection: 'row', alignItems: 'center' },
  logo: { height: 80, width: 160, objectFit: 'contain' },
  companyTh: { fontSize: 28, color: '#5b9bd5' },
  docTitle: { fontSize: 16, fontWeight: 'bold', textAlign: 'center', marginVertical: 15 },
  table: { width: '100%', borderWidth: 1, borderColor: '#000' },
  tableRow: { flexDirection: 'row', borderBottomWidth: 1, borderColor: '#000', minHeight: 16 },
  th: { fontWeight: 'bold', textAlign: 'center', padding: '2 5', borderRightWidth: 1 },
  td: { padding: '2 5', borderRightWidth: 1 },
  footerSection: { flexDirection: 'row', justify: 'space-between', marginTop: 30 }
});

// 3. Export PDF Document Component
export const DeliveryNotePDF = ({ order, items, profile }) => {
  const MIN_ROWS = 15;
  const paddedItems = [...items];
  while (paddedItems.length < MIN_ROWS) paddedItems.push({});

  return (
    <Document>
      <Page size="A4" style={styles.page}>
        {/* Header */}
        <View style={styles.headerSection}>
          <Image src="/images/logo.png" style={styles.logo} />
          <View>
            <Text style={styles.companyTh}>บริษัท ฟอร์ท คอร์ปอเรชั่น จำกัด (มหาชน)</Text>
            <Text style={{ fontSize: 12, color: '#5b9bd5' }}>FORTH CORPORATION PUBLIC COMPANY LIMITED</Text>
          </View>
        </View>

        {/* Title */}
        <Text style={styles.docTitle}>ใบนำส่งอุปกรณ์</Text>

        {/* Table */}
        <View style={styles.table}>
          <View style={[styles.tableRow, { backgroundColor: '#f8fafc' }]}>
            <View style={[styles.th, { width: '10%' }]}><Text>ลำดับ</Text></View>
            <View style={[styles.th, { width: '50%' }]}><Text>รายการ</Text></View>
            <View style={[styles.th, { width: '15%' }]}><Text>จำนวน</Text></View>
            <View style={[styles.th, { width: '25%', borderRightWidth: 0 }]}><Text>S/N</Text></View>
          </View>
          {paddedItems.map((item, idx) => (
            <View key={idx} style={styles.tableRow}>
              <View style={[styles.td, { width: '10%', textAlign: 'center' }]}><Text>{item.name ? idx + 1 : ''}</Text></View>
              <View style={[styles.td, { width: '50%' }]}><Text>{item.name || ''}</Text></View>
              <View style={[styles.td, { width: '15%', textAlign: 'center' }]}><Text>{item.quantity ? `${item.quantity} ${item.unit}` : ''}</Text></View>
              <View style={[styles.td, { width: '25%', borderRightWidth: 0 }]}><Text>{item.sn || ''}</Text></View>
            </View>
          ))}
        </View>

        {/* Signatures Container */}
        <View style={styles.footerSection} wrap={false}>
          <View style={{ width: '45%' }}>
            <Text>ผู้ส่งของ: ____________________</Text>
          </View>
          <View style={{ width: '45%' }}>
            <Text>ผู้รับของ: ____________________</Text>
          </View>
        </View>
      </Page>
    </Document>
  );
};

7 การแก้ปัญหาและข้อควรระวัง (Gotchas & Best Practices)

Tips

1. บั๊ก Vite `Buffer is not defined` ใน React-PDF

เมื่อใช้ @react-pdf/renderer บน Vite Development Server อาจเกิด Runtime Error เนื่องจากขาด Node Polyfills ในเบราว์เซอร์

แก้ไขโดยใส่ Polyfill Script สำหรับ Buffer ใน index.html: <script src="https://esm.sh/buffer@6.0.3"></script>

2. การป้องกันส่วนลายเซ็นโดนตัดขาดครึ่งหน้า (Signature Orphan)

หากรายการตารางมีจำนวนมาก ลายเซ็นอาจตกไปอยู่ที่ขอบล่างของหน้ากระดาษและถูกตัดครึ่ง

แก้ไขโดยใช้พร็อพ wrap={false} ครอบก้อน <View style={styles.footerSection} wrap={false}> เพื่อยกก้อนลายเซ็นทั้งหมดไปไว้หน้าถัดไปพร้อมกัน

3. การตรึงตารางว่างขั้นต่ำ (Min Row Padding)

กรณีมีรายการเบิกเพียง 1-2 รายการ ตารางจะดูสั้นเกินไป ไม่สวยงามเท่าแบบฟอร์มกระดาษมาตรฐาน

แก้ไขโดยการวนลูปเติม Empty Row ให้กับ Array ของ items ให้มีจำนวนขั้นต่ำ 15 แถวเสมอ (MIN_ROWS = 15)
